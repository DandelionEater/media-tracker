# Seenary 0.1.7 Beta

Tag: `v0.1.7-beta`

## Highlights

This update expands Seenary into an Anime and Manga library while continuing to polish everyday navigation, details, privacy, synchronization, and data safety.

## New and improved

- Home and My List now share one responsive **Library Lens** instead of separate page-specific switches. A single control combines the Anime/Manga context with Personal, Discover, and My List destinations, persists both choices, migrates the previous saved tabs, and follows the media type of titles opened from search or relations.
- The navbar's My List shortcut now yields while the Library Lens is visible, avoiding duplicate My List controls, and returns automatically after the Lens scrolls out of view or the user opens a page without it.
- A global scroll-to-top button now appears after meaningful vertical scrolling across Home, Discover, search results, My List, media details, and Settings. It follows the active page surface, stays clear of the center quick-actions pill, and returns smoothly to the top without reacting to horizontal shelves or nested notification and modal scrolling.
- Manga Personal now mirrors the full Anime dashboard with its own reading spotlight, matching overview metrics, status totals, Continue Reading, Plan to Read, favorite-based recommendations, Recently Updated section, card density, carousel behavior, and configurable layout. Spotlights distinguish Watching or Reading, Up Next, and other list picks; Manga statistics keep chapters and volumes separate from Anime progress, and rearranging Manga Home never rearranges Anime Home. Manga Discover also includes a trending carousel plus Publishing Now, New & Noteworthy, Popular, and Highly Rated shelves.
- Personal's **Recently Updated in Seenary** shelves now reflect only direct changes made inside Seenary. Imports and third-party pulls can update library data without flooding or reordering this personal history, while backups preserve genuine local-activity timestamps.
- Anime and Manga Discover now load together behind the scenes. Switching the Library Lens reuses what Seenary already has instead of requesting the same overview again, while longer shelf pages load only when opened.
- Search now finds Anime and Manga together, separates them into clearly labelled sections with independent counts, and places the active Library Lens type first. Manga results include chapters, volumes, format, score, and artwork and can be opened or tracked directly.
- Airing and publishing status pills are now color-coded consistently across media details and My List for quicker scanning. Upcoming titles use red, currently airing or publishing titles use green, and finished titles use blue. Format, season, and episode information on details pages use their own separate violet, amber, and silver treatments so they do not compete with status colors.
- Anime formats now preserve familiar capitalization, including `TV` and `TV SHORT`.
- Anime and Manga details now request AniList's extra-large cover artwork. Covers remain compact on the details page and open no larger than their natural size in the artwork inspector, preserving more detail for deliberate zooming. Banners also open at their natural size instead of being stretched to fill the inspector.
- Artwork inspector controls now occupy and cover the quick-actions pill's bottom-screen position while inspection is active instead of following the artwork's height. Short banners no longer leave the control pill floating across the middle of the enlarged image.
- Artwork inspector wheel zoom now anchors to the cursor like CAD and map applications in both directions: the point beneath the pointer remains in place while zooming in or out, without the shrinking pan boundary pulling the image toward center. Reaching the fitted 100% view recenters it cleanly. Double-click zoom uses the clicked point as its anchor, while the dedicated zoom buttons intentionally remain center-based.
- Re-enabling the 18+ filter now immediately removes adult titles from already-loaded search, trending, Discover, and expanded shelf content. Opening a previously cached adult title shows a privacy-safe hidden state, and saved adult titles—including older entries Seenary classifies automatically—remain in My List with their title, artwork, notes, and recommendation metadata redacted instead of losing personal progress.
- Searches with no matches now show a clear empty-results message with suggestions instead of silently returning to the home screen. Searches whose matches are all hidden by the 18+ filter explain that separately, and every search state is positioned safely below the navigation bar.
- Pressing Enter while the search field is focused now dismisses the search results and returns to the home content without clearing the query. Focusing the field again restores the retained search, while Delete continues to clear it explicitly.
- Controls used with the mouse no longer retain Enter and accidentally reopen themselves the next time it is pressed. Enter reliably returns to the global search shortcut after mouse navigation, while controls deliberately reached with Tab or the arrow keys still respond normally to Enter and Space.
- Typing while search is unfocused now preserves the first typed character. Type-to-search focuses the field without selecting and replacing that initial input, while explicit Enter or mouse focus can still select an existing query for convenient replacement.
- Returning focus to a retained search now reruns the query with the current 18+ preference instead of restoring stale results. This makes switching the filter in either direction consistent without requiring the user to edit the query manually.
- Manga search results now open a Manga-specific details page using the same visual style as Anime details. It shows known chapters and volumes, publishing status and dates, publication age, creators, characters, relations, recommendations, official links, artwork, scores, genres, and tags while leaving out Anime-only controls. Anime adaptations and their source Manga can be opened safely in either direction.
- My List now supports Manga with Reading, Plan to Read, Completed, Paused, and Dropped sections across List, Grid, and Board views. Anime and Manga remember their own view, sorting, expanded sections, filters, and section order.
- My List filters now focus on useful library details instead of repeating its status shelves: Rating includes score bands, Format uses Anime- or Manga-specific labels, and Genres and non-spoiler Tags support searchable multi-selection. Optional release years and Anime seasons, recent activity, episode or chapter ranges, and a Favourite-only toggle make titles easier to recover from memory. Genres and tags also participate in normal My List search.
- Manga tracking now works throughout Manga details and My List. Users can track chapters and volumes separately, score and favorite titles, save notes and dates, manage rereads, increment progress quickly, mark publications complete, and remove entries without affecting Anime records.
- Manga details now recognize AniList's current publishing states, including `HIATUS` and `CANCELLED`, and use more useful wording when chapter or volume totals are missing: ongoing publications show `Ongoing`, future titles show `TBA`, hiatus titles show `Unconfirmed`, and finished titles with incomplete metadata show `Not listed`.
- Seenary now opens Home with less initial work and loads Settings, media details, and My List only when first needed.
- Native browser hints across Seenary have been replaced with one reusable animated tooltip that supports hover and keyboard focus. Compact Anime and Manga overview totals now reveal their exact values, while Time Watched presents a rolling two-unit summary and expands to years, days, hours, minutes, and total accumulated hours on demand.
- Search-result cards now keep tracked status and progress hidden until hover, shifting their existing details smoothly to make room while retaining quick list actions.
- Personal Anime and Manga cards now use the same visual language as Discover: formats are blue, ratings amber, time and season information violet, sources green, and favorites or popularity rose. This makes card details easier to scan wherever a title appears.
- Settings now presents **Startup view** before the Home-specific behavior controls, since the landing destination is the first choice that takes effect. The General summary also shows the saved desktop hide/show shortcut—or clearly says when it is disabled—without requiring the section to be opened.
- Seenary now has a completely redesigned Windows installer that looks and feels like part of the app instead of a stock setup wizard. Its borderless dark interface provides a clear **Install Seenary** action, with optional choices for installing just for yourself or everyone, changing the installation folder, and creating a desktop shortcut. Dedicated installation, success, and failure screens keep the whole setup experience consistent while preserving Seenary's existing automatic-update and uninstall behavior.
- Anime **Watch & Links** and Manga **Read & Links** now separate viewing or reading providers from official and social pages instead of mixing every destination into one grid. Manga providers use clear **Read online** and language labels instead of AniList's generic Streaming wording, while familiar services use recognizable but comfortable brand colors. Anime also groups direct episode links, opens the list around the next unwatched episode, and marks it **Up next** based on saved progress. Provider availability can vary by region.
- Text and PDF imports now ask whether a file contains Anime or Manga. Each choice searches the matching type, previews episode or chapter progress, and saves selections to the correct library; Anime remains the default for older import workflows.
- Signing up with AniList or MyAnimeList, or linking either service later, now brings in both Anime and Manga immediately. If the first import cannot finish, login still succeeds and Seenary explains that the import can be retried.
- Public username imports now support both Anime and Manga from AniList and MyAnimeList, with separate labels, status and progress in the review screen. A MyAnimeList account does not need to be linked to copy a public list; linking is reserved for private-list access and ongoing synchronization.
- Manual and automatic sync now handle Anime and Manga through the active linked service. Manual sync sends all waiting changes in one run, while automatic sync can deliver additions, edits, progress, and deletions in the background. Feedback appears only after the service responds and names the title, provider, and successful, partial, or failed result.
- **Update from third party** now pulls Anime and Manga together from AniList or MyAnimeList. Manga keeps reading status, chapter and volume progress, scores, notes, dates, and rereads, and pulled changes are recorded without being sent straight back to the service they came from. Titles that cannot be matched safely are named in a partial-update message instead of being silently skipped.
- Sync Activity now includes a dedicated Pulled tab alongside outbound Completed and Failed history. It preserves per-title changes and readable conflicts, follows the user's title-language preference, and keeps Anime and Manga records separate so titles with similar identifiers cannot overwrite or mislabel one another. Older Anime history upgrades automatically.
- Sync Activity now prevents an unsendable change from retrying forever. After five failed attempts, Seenary moves it to a new **Excluded** tab and stops sending it automatically; users can also exclude a waiting change after its first failure. Each entry keeps the title, provider, attempted changes, failure reason, and whether Seenary or the user excluded it. **Restore sync** returns it to the queue whenever the underlying problem has been resolved.
- Portable backups now use one version 4 format across browser and desktop. They can preserve the full Anime and Manga library, progress, pending and excluded sync work, sync history, settings, navigation choices, separate My List preferences, configurable layouts, and the automatic-sync preference. Import shows a summary first, lets users restore the library and preferences separately, and can optionally restore the desktop shortcut, window size, and launch-at-login choice without importing credentials or old monitor positions. Backups from versions 1 through 3 remain supported.
- Settings now provides separate **Clear Anime list**, **Clear Manga list**, and **Clear all media** actions with a roomy approval window that names the exact scope. **Seenary only** is the safe default and creates no linked-service deletion jobs; users can instead explicitly choose **Seenary + provider** when they also want matching AniList or MyAnimeList entries queued for removal. The approval window shows whether automatic sync is on or off and explains whether those optional provider deletions will be sent automatically or wait for a later sync.
- Users can now permanently delete their Seenary account from the Danger zone. Deletion requires opening a second confirmation and typing the exact username, then removes Anime and Manga list data, sync activity, linked-service connections, signed-in sessions, locally saved app data, and desktop layouts. It does not delete the user's AniList or MyAnimeList account or remote lists.

## Reliability and fixes

- AniList and MyAnimeList pulls now preserve missing start and completion dates as genuinely unset instead of replacing them with the current date. This prevents unchanged Watching and Completed entries from being repeatedly reported as updated on later pulls.
- Seenary now permits one linked sync provider per profile and provides a safe unlinking flow before switching services. Unlinking verifies a local password—or helps external-sign-in-only profiles create one—then clears only that provider's waiting changes while preserving the Seenary library and activity.
- Clearing a score or note now truly clears the previous value on MyAnimeList instead of leaving the old remote value in place.
- MyAnimeList Anime pull conflicts now name the skipped title and explain when separate MyAnimeList entries cannot be represented safely as one AniList title, preventing one entry from silently overwriting another.
- Imported Anime now retain episode duration information, and existing watched entries with missing duration are repaired automatically when the library loads. This fixes Time Watched totals being too low after imports in `0.1.6-beta`, including for older and partially watched titles.
- Returning from a title's details to My List now restores the previous vertical position instead of jumping back to the top, and transitions directly without briefly showing an unloaded Home page while the list refreshes. This keeps the last opened title in view while working through long sections and libraries with hundreds of entries.
- Opening and closing My List filters is now immediate, even with a large library. The filter panel no longer repeatedly shifts the entire page or refreshes every visible card just to show or hide its controls.
- Personal recommendations no longer make the page wider than the Seenary window. Accidental page-level horizontal scrollbars are blocked across the app while intentional sideways shelves continue to work normally.
